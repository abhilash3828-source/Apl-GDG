# 📚 VidyaSathi — UP Board AI Tutor

> UP Board ke Class 9-12 students ka AI-powered Hindi Tutor

🌐 **Live Demo:** [vidyasathi.github.io](https://abhilash3828-source.github.io/Apl-GDG/)

---

## 🎯 Problem Statement

Uttar Pradesh mein lakhs students hain jo quality education se door hain:
- Coaching afford nahi kar sakte
- Hindi medium mein guidance nahi milti
- 24/7 doubt solving possible nahi

**VidyaSathi in sabka solution hai.**

---

## 💡 Solution

VidyaSathi ek AI-powered tutor hai jo:
- **Hindi, Hinglish, ya Awadhi** mein padhata hai
- **UP Board syllabus** ke hisaab se answer deta hai
- **Practice questions** generate karta hai exam style mein
- **Galat jawab** pe pyaar se correct karta hai
- **24/7 free** available hai — sirf ek smartphone chahiye

---

## ✨ Features

| Feature | Description |
|--------|-------------|
| 🌍 Multi-language | Hindi, Hinglish, Awadhi support |
| 📖 UP Board Syllabus | Class 9, 10, 11, 12 — Math, Science, Hindi, SST, English |
| 📝 Practice Questions | UP Board exam style MCQ & short answers |
| 🤖 AI Powered | Groq API — Llama 3.3 70B model |
| 📱 Mobile Friendly | Responsive design — smartphone pe bhi chale |
| ⚡ Fast | Real-time responses |

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript
- **AI Model:** Llama 3.3 70B via Groq API
- **Hosting:** GitHub Pages
- **No backend needed** — pure client-side app
